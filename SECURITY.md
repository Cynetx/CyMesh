# Security

Please report suspected vulnerabilities privately through the repository’s **Security → Report a vulnerability** feature when it is enabled. If private reporting is unavailable, contact the [Cynet team](https://cynetx.ir/) and ask for a private channel before sharing details.

Include the affected version or commit, affected component, expected and observed behavior, and steps to reproduce using test data. Keep recovery phrases, PINs, vaults, peer invitations and private bridge addresses out of public issues.
